# stock-data

ウォッチ銘柄の株価データを、GitHub Actions で平日1日4回自動取得して保存する場所です。
Claude の予約レポート（寄り付き前・前引け後・大引け後）は、ここのデータを読んで分析します。
パソコンを閉じていても動きます。

## 中身
| 場所 | 内容 |
|---|---|
| `tickers.txt` | ウォッチ銘柄の一覧。行を足す・消すだけで対象を変えられます |
| `data/latest.json` | 最新の取得結果（更新時刻、各銘柄の最新値、市場指標、約定回数ランキング、エラー） |
| `data/daily/コード.csv` | 各銘柄の日足（約1年分） |
| `data/market/*.csv` | 日経平均・ドル円・SOX指数・米10年金利 |
| `scripts/fetch_prices.py` | 取得プログラム |
| `.github/workflows/fetch.yml` | 自動実行の設定（平日 7:35／11:50／15:38／16:20 JST） |

## 手動で動かすには
GitHub の「Actions」タブ →「株価データの取得」→「Run workflow」。

※ 公開データのみを保存しています。保有株や買値などの個人情報は置きません。
